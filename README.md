# Tech Lab Website

The source code and assets for the official website of our Tech Lab. This platform serves as our central hub to showcase active projects, announce upcoming events, and maintain our member directory.

## Core Features
* **Project Portfolio:** A showcase of technical applications and research built by lab members.
* **Member Profiles:** A registry highlighting roles, core skills, and individual contributions.
* **Lab Updates:** A central board for announcements, workshops, and hackathon schedules.
